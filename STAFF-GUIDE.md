# How to update the website (for agency staff)

1. Go to app.pagescms.org and sign in with GitHub.
2. Open the raleigh911 site.
3. Pick what you want to change from the list:
   - Board of Directors: members and meeting dates. Past dates turn gray by themselves. To start a new year, change the year and replace the dates.
   - Home page notice: type a message and switch Show on. Switch it off when done.
   - Statistics: add the new year in Years, then add that year's number to each type, in the same order.
   - Phone numbers, Staff, Links: add, remove or fix an entry.
   - Pages (About, Addressing, LEPC and others): edit the text like a normal document.
4. Click Save. The live site updates in about a minute.

You cannot break the design by editing text. If something looks wrong, call the person who set this up.
